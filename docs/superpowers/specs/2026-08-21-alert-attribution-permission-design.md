# 告警、跨实验归因与权限管理设计

## 目标

在现有静态实验资产中心中补齐三条可操作链路：配置并启停告警规则、从异常实验扫描其他运行实验并给出可解释的嫌疑排名、按角色和数据范围控制台账与规则能力。同时整理实验评估、分流方案和上线前检查的职责边界。

## 信息架构

- 左侧“追溯复盘”改名为“实验管理”，顺序为实验清单、父子实验、放量历史、批量导入记录。
- “监控排查”保持一个左侧入口，页内使用 `告警中心 / 异常归因 / 规则配置` 三段导航。
- 管理员账号菜单继续承载权限配置入口，普通用户主导航不出现权限管理。

## 功能边界

### 实验评估

除样本量和周期外，增加流量覆盖、基线稳定性、实验污染、护栏完整度、业务收益门槛五维判断。输出可执行替代方案：扩大客群、调整 MDE、减少分组、延长周期、准实验、前后对比。

### 分流方案

Seed 页面改为分流方案登记，只负责 Seed、分流层、比例、实验单位、样本口径和历史复用风险。删除 Pre-AA、均匀性、正交性列；选定方案后带入上线前检查。

### 上线前检查

统一执行 Pre-AA、均匀性、正交性和规则冲突。范围支持全部运行实验、同业务域、同分流层和手动指定。

## 告警规则

告警规则包含指标类型、阈值、比较符、连续周期、严重度、作用范围、通知对象、状态、版本和最近命中。管理员维护模板和阈值上下限；实验负责人可管理自己实验的规则并在允许范围内调整；普通用户只读。

## 跨实验异常归因

用户从告警点击“分析影响来源”，系统针对目标实验扫描运行实验。评分由样本重叠 35%、放量时间吻合 25%、分流层/规则交叉 20%、指标同步变化 15%、已登记关系 5% 组成。结果展示候选实验、负责人、放量变化、证据、联系动作，并标注“关联嫌疑，不代表因果”。

扫描可覆盖全部运行实验；超出用户可见范围时，只展示实验编号、风险原因和负责人，隐藏策略及指标明细。

## 权限管理

角色包括管理员、业务负责人、实验负责人、分析人员、只读用户。每个角色配置模块、操作权限、业务域/实验可见范围、负责人或代理人、规则阈值范围和变更记录。

## 静态 Demo 约束

- 不接后端，所有状态在 React 本地状态中模拟。
- 所有按钮必须产生筛选、状态变更、页面切换、抽屉或 toast 反馈。
- `src/` 与生成的 `dist/index.html` 必须同步。
- 继续支持直接通过 `file://` 打开。

## 验收

- 告警规则可新增、编辑、启停并产生变更记录。
- 告警可进入归因页，并看到可解释的候选排名和负责人。
- Seed 页面不再执行统计校验，上线前检查支持范围选择。
- 权限页可切换角色、修改范围并记录变更。
- 父子实验位于“实验管理”分组的实验清单下方。
- `npm run verify:all` 和截图回归通过。
